## Recent updates worth watching

### GitHub Copilot

- **Computer use in public preview:** Copilot CLI and the GitHub Copilot app on macOS and Windows can now interact with desktop apps. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-github-copilot-can-now-interact-with-desktop-apps)
- **Copilot app for Beginners series:** Short guides on [running several agents at once](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-run-several-agents-at-once/), [using the diff, terminal, and browser](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-using-the-diff-terminal-and-browser/), and [automating Dependabot pull request triage](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-automate-dependabot-pull-request-triage/). Source: [The GitHub Blog](https://github.blog/latest/)

### GitHub Actions

- **macOS 14 runner image retirement:** The image will be retired on November 2, 2026, with temporary brownout failures beforehand. Check your `runs-on` labels. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-github-actions-macos-14-runner-image-retirement)

### Collaboration and security

- **Confidential comments on repository security advisories:** Visible only to people with write access, so teams can discuss a report privately from the reporter. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-02-confidential-comments-on-repository-security-advisories)
- **Git 2.56:** GitHub's look at the notable changes in the latest Git release. Source: [The GitHub Blog](https://github.blog/open-source/git/highlights-from-git-2-56/)
